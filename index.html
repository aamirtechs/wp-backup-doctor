wp-backup-doctor

Audit a WordPress backup manifest or listing for missing, stale and empty backups.

Your report will appear here.

A JSON manifest is a list of entries with name, size, modified date and type. A listing has one entry per line: name size ISO-date [type]. Backup age is measured against the current time, like the CLI.
